# SLUM v1.0.0

Erste installierbare Version des PixInsight-Skripts SLUM mit eigenem SVG-Icon unter **Script → Utilities → SLUM**.

## Installation

1. `SLUM-v1.0.0.zip` herunterladen und entpacken.
2. In PixInsight **Script → Feature Scripts… → Add** öffnen und den entpackten Ordner `SLUM` wählen.
3. Die Erkennung abschließen. Anschließend **Script → Utilities → SLUM** starten.

Die JavaScript-Dateien und `SLUM.svg` müssen zusammen im Ordner `SLUM` bleiben. Das ZIP enthält eine kurze `INSTALL.txt`. Voraussetzung ist PixInsight **1.9.6 oder neuer**.

## Funktionen

- Zwei bis vier lineare L/R/G/B-Master als Dateien oder geöffnete Ansichten.
- SPFC-Flux als bevorzugte Normalisierung; LinearFit als ausdrücklicher Fallback mit Referenz-Override.
- SLUM als neue XISF-Datei oder als PixInsight-Ansicht, ohne Originale zu verändern.
- Zwei Stufen mit einstellbarem L-Anteil von 50–80 %; RGB standardmäßig nach Noise, optional mit manuellem R/G/B-Override.
- Gemischtes 1×1/2×2/3×3-Binning bei gemeinsamem Ausgaberaster. Die automatische RGB-Gewichtung bei gemischtem Binning ist eine Heuristik.

Die Master müssen vor dem Lauf linear, registriert, gleich beschnitten und gradientenkorrigiert sein. Das Skript registriert oder resampelt nicht. Fehlende WCS-Daten werden im Protokoll erwähnt; deutliche WCS-Versätze und unterschiedliche Bildabmessungen werden abgewiesen.

## Prüfung

Node-Tests sowie native PixInsight-Proben für SPFC, LinearFit, gemischtes Binning, Datei-/Ansichtsausgabe, Originalschutz und Abbruch-Cleanup bestanden. Das Release-ZIP enthält ausschließlich die benötigten Skriptdateien, das Icon und die Installationsanleitung.
