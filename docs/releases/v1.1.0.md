# SLUM v1.1.0

Neu: **SLUM für Siril** (`SLUM-Siril-v1.1.0.zip`, Siril 1.4 oder neuer). Die PixInsight-Version (`SLUM-v1.1.0.zip`) ist inhaltlich unverändert gegenüber v1.0.1.

## Siril-Version

- Gleiche Gewichtsregel wie in PixInsight (`1/noise²` innerhalb RGB, L-Anteil 50–80 %), LinearFit mit wählbarer Referenz.
- Quellen: Dateien oder das aktuell geladene Siril-Bild; Ergebnis ist eine neue 32-Bit-FITS-Datei, optional in Siril geöffnet.
- Kein SPFC-Flux. Die Rauschmessung ist eine eigene numpy-Umsetzung und weicht leicht von PixInsights NoiseEvaluation ab.
- Geprüft mit Siril 1.4.5 und synthetischen Daten (Pipeline und Oberfläche); 20 Unit-Tests.

## Installation

Siehe `INSTALL.txt` im jeweiligen ZIP. PixInsight: Ordner `SLUM` über Feature Scripts hinzufügen. Siril: Ordner `SLUM-Siril` in die Skriptpfade aufnehmen.
