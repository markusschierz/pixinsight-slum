# SLUM v1.0.1

Korrigiert die PixInsight-Menüeinordnung: SLUM erscheint mit seinem SVG-Icon unter **Script → astro-foto.ch → SLUM**.

## Installation und Aktualisierung

1. `SLUM-v1.0.1.zip` herunterladen und entpacken.
2. In PixInsight **Script → Feature Scripts…** öffnen. Alte SLUM-Einträge entfernen, insbesondere solche aus temporären Verzeichnissen.
3. **Add** wählen, den entpackten Ordner `SLUM` auswählen und die Erkennung abschließen.

Die Dateien im Ordner `SLUM` zusammenlassen. Voraussetzung ist PixInsight 1.9.6 oder neuer. Die Bildberechnung entspricht v1.0.0; Eingaben bleiben unverändert.
